# ChatGPT Intelligence - Brand Assets

This directory is reserved for the complete **v1.4.0 branding package** supplied as `chatgpt-intelligence-brand-final-v1.4`.

The original package includes 56 payload files recorded in its `MANIFEST.json`, plus the manifest itself:
- `BRAND-GUIDELINES.md`
- `design-system/` - neutral light/dark design tokens
- `banners/` - README hero artwork in PNG and SVG
- `icons/` - app icon variants at seven sizes and two themes
- `logos/` - lockups, wordmarks, and symbols
- `social/` - GitHub social images
- `preview/` - a static HTML sample with a light/dark toggle
- `asset-contact-sheet.png` - design overview

## Publication status
**The archive was validated locally. The brand guidelines and design tokens are published; the complete binary artwork is not yet published through this connector.** Do not treat listed asset paths as published until directly verified on `main`.

The original package `README.md` must be stored here, **never replace the root repository README**. All assets should retain their exact relative names and bytes in this subdirectory. The design is intentionally ChatGPT-like, not an official OpenAI interface or official brand.

## Branding vs. Intelligent UI
These SVG/PNG/HTML assets establish a project visual identity. They do not change the native ChatGPT application's colors or components. `/INTEL UI` means selecting **available ChatGPT output components** based on information needs, not applying an HTML skin from this package.

## Trademark
The name `ChatGPT` is an OpenAI mark. The project's independent identity must not imply affiliation. Review the current [OpenAI brand guidelines](https://openai.com/brand/) before public product promotion.
