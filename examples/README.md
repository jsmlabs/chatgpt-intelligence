# Examples

Start with [INTEL Conversation Examples](intel-command-examples.md) to see the proposed command workflow and its failure cases. These are design examples, not client test records.

Examples should demonstrate the difference between a clear response and an unnecessarily complex one.

## Example: a simple question
**Question:** What is context engineering?

**Clear answer:** Context engineering is the practice of selecting and organizing information that an AI system needs for a particular task.

**Less useful answer:** A long diagram and multiple dashboards that bury the definition.

## Example: comparing options
When comparing three approaches against the same criteria, a compact table can be more useful than unrelated paragraphs.

Examples are illustrative, not evidence that ChatGPT will behave identically across models or interfaces. Use only synthetic personal data.
