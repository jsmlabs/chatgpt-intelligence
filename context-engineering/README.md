# Context Engineering

## What is it?
Plan which instructions, facts, relevant preferences, and other context matter for a particular task.

## Core idea
Context is task-specific. Available sources vary by product, feature, permissions, and session.

## How to use this section
Separate instruction priority from information relevance. Prefer the minimum sufficient context and flag conflicts or missing facts.

## Example question
Which context is necessary for the current task?
