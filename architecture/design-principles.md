# Design Principles

1. **Mission first:** All work supports the project's stated ChatGPT research and experience goals.
2. **Understandable by default:** Start in plain language; introduce technical detail only when useful.
3. **Evidence before certainty:** Label observed facts, proposals, and unknowns accurately.
4. **One source of truth:** Store a concept once and link to it elsewhere.
5. **Structure before decoration:** Select UI only after the information hierarchy is clear.
6. **Adaptive, not rigid:** Choose response patterns based on the user's real task.
7. **Privacy by design:** Do not publish sensitive memories, prompts, or personal information.
8. **Version awareness:** Product features change; state verification date and applicable context.
9. **Testable claims:** Important requirements should have examples and acceptance criteria.
10. **Minimal complexity:** Add files, schemas, or automation only when they solve a real problem.

These are project principles, not instructions that override ChatGPT's own policies or user controls.
