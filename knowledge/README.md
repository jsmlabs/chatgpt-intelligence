# Knowledge

## What is it?
Organize facts, sources, reference material, uncertainty, and changes over time.

## Core idea
Knowledge documents should distinguish current supported facts from assumptions and dated observations.

## How to use this section
Link authoritative sources, record when facts were checked, avoid duplication, and update or mark stale material.

## Example question
Which source supports this product capability and when was it checked?
