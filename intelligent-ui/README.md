# Intelligent UI

## What is it?
Choose response structure, formatting, visualization, and interaction based on the information need.

## Core idea
Design information architecture before selecting UI components. Components must help, not decorate.

## How to use this section
Use prose for simple answers, tables for precise comparisons, diagrams for relationships, and interactions only when useful and supported.
